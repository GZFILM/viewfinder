# Viewfinder FX30

Director's viewfinder for the phone. Simulates Sony FX30 (Super 35) and Full Frame framing for any focal length and aspect ratio, with composition guides (rule of thirds, phi grid, golden spiral, one-point perspective, dynamic symmetry and more), a horizon level, and stills with lens metadata.

Open on a phone: https://gzfilm.github.io/viewfinder/
